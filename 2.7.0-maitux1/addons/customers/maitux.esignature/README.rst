MEDAI  E-Signature
=========================

This package provides the initial add-on skeleton for the 
workflow re-auth electronic signature MVP.

Current scope:

- installable Plone/ add-on
- browser layer registration
- minimal control panel entry
- overview browser page
- package layout for browser/services/adapters/guards/storage

The full electronic signature workflow, re-auth provider, guard adapter,
and audit integration are implemented in later MVP steps.
